# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 요구사항 요약
> 유저가 입력한 로또 구입 금액에 맞는 <로또 묶음> 발급

### 도메인 역할 정리
이 프로젝트는 로또 게임의 핵심 비즈니스 로직을 여러 도메인 객체로 분리하여 각자의 책임을 다하도록 설계되었습니다. 각 도메인의 역할은 다음과 같습니다.
- ✅ (적용) ❌ (미적용) ⚠️ (개선 대상)
*   **`Ticket`**: 로또 한 장을 의미하는 객체입니다. 6개의 로또 번호(`LottoNumber`)를 가지며, 번호는 중복되지 않는 숫자로 6개로 구성됩니다. [✅]
*   **`LottoNumber`**: 로또 번호 하나를 표현하는 객체입니다. 1부터 45까지의 숫자만 허용하도록 값을 제한합니다. [✅]
*   **`LotteryWinningNumbers`**: 당첨 번호 6개와 보너스 번호 1개를 가지고 있는 객체입니다. 사용자의 로또와 비교하여 당첨 등수를 판단하는 기준이 됩니다. [✅]
*   **`WinLevel`**: 3개 일치(5등)부터 6개 일치(1등)까지의 당첨 등수와 각 등수의 당첨 금액 정보를 가지고 있는 Enum 입니다. [✅]
*   **`StatBoard`**: 구매한 모든 로또의 당첨 통계를 관리하는 객체입니다. 각 등수별 당첨 횟수와 총 수익률을 계산하는 역할을 담당합니다. [✅]
*   **`TicketBooth`**: 로또를 전달하는 역할을 담당합니다. DrawMachine과 상호작용하여 요구사항에 맞게 중복되지 않는 6개의 숫자를 오름차순으로 정렬하여 `Lotto` 객체를 생성합니다. [✅]
*   **`AutoDrawMachine`**: 로또를 생성하는 역할을 담당합니다. 요구사항에 맞게 중복되지 않는 6개의 숫자를 오름차순으로 정렬하여 `Lotto` 객체를 생성합니다. [✅]
*   **`ManualDrawMachine`**: 로또를 생성하는 역할을 담당합니다. 요구사항에 맞게 중복되지 않는 6개의 숫자를 입력받아 오름차순으로 정렬하여 `Lotto` 객체를 생성합니다. [✅]


### 제약 사항
1. 로또 1장당 1000원
2. 로또의 숫자는 6개다.

### 입력 사항
1. 구입 금액
2. 지난 주 당첨 번호 입력
3. 보너스 볼 입력받는다.

### 출력 사항
1. 구입 금액에 따른 구매한 로또 장수
2. 구매한 로또별 로또 번호
3. 당첨 번호 기반 유저 로또 당첨 통계
   3-1. 당첨 일치한 개수반환 (3개 ~ 6개 일치) [* 5개 일치는 보너스 볼 일치도 포함]
   3-2. 총 수익율 소수점 2자리까지 반환 -> (기준: 유저가 구입한 금액을 1로 지정)

## 핵심 비즈니스 로직

### 로또 생성기
1. 1 ~ 45까지의 자연수 숫자이다.
2. 집합으로 만든다 (중복된 숫자 묶음 X)
3. 오름차순으로 랜덤 생성한다.

### 당첨 번호 기반 통계 계산기
1. 6개 일치 > 5개 + 보너스 볼 일치 > 5개 일치 > 4개 일치 > 3개 일치로 통계를 만든다.
2. 총 수익율을 계산해서 출력한다.
